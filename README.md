"The Keyhole in the Sky" — a tiny lone robot on a dark ridge looks up as a colossal stone door floating in a teal dusk sky cracks open at its keyhole, pouring a diagonal torrent of amber light down onto it. One bold moment of impossible scale, drawn entirely in code: `main.ts` (Node 22, standard library only) renders the scene procedurally and writes its own PNG to `/output/entry.png`. No image assets, no randomness, no network — every run writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
